# Pi5 Edge 공개 소스 검증 — 2026-10-15

## 이번 PR에서 확인한 범위

기존 팀 PR과 Pi5 작업 사본을 수정하지 않고 새 공개 저장소에 소스를 복사했습니다. 최신 공통 PC/모바일 웹 UI, 이메일·Android FCM 연동, 로컬 시작/중지/보정·설정 제어, DB migration 0005, 전체 서비스 자원 모니터가 포함됩니다. 담당자 확인이 끝난 낙상 이력을 다시 실시간 수신해도 경고창을 재노출하지 않도록 UI를 보완했습니다.

이번 실행 환경은 **Windows x86_64 / Python 3.12.12 / Node 24**입니다. Pi5 ARM64 실행이나 Pi5 성능 에뮬레이션이 아닙니다. 원본 작업 사본의 가상환경을 변경하지 않고 새 full/lean 환경을 만들었습니다. lean 환경에는 Torch가 없고 CPU 피처 결과를 full 환경과 비교합니다. 테스트 DB는 새 loopback 전용 PostgreSQL 16이며 기존 운영 DB와 분리했습니다. 센서 접근과 외부 이메일/푸시 연결은 차단했습니다.

최종 회귀 수와 빌드 결과는 [기계 판독 결과](validation-20261015.json)에 기록합니다. 테스트 개수에는 하위 릴리스 프로필 검사를 중복 합산하지 않습니다. UI를 새로 export한 뒤 프로젝트 node_modules 없이 로그인 SSR와 정적 asset HTTP 응답을 확인했습니다.

새 체크아웃에서 합성 WGSP RAW를 10초 재생하고 실제 원본 ONNX를 로드했습니다. 3,232프레임, 추론 14회, CRC/프로토콜 거부·순번 손실·기한 누락 0이었습니다. 초기 창 충족 전 invalid 6회와 stale 1회는 있었고 정상 구간에서는 둘 다 0이었습니다. 처리 P95 190.40ms/최대 198.88ms는 제한하지 않은 x86 호스트의 Edge 프로세스만 측정한 값입니다. 짧은 경로 확인이므로 운영 live timing gate나 Pi5 전체 자원 검증 통과로 표기하지 않습니다.

## 이전 완성 배포본 증거와 구분

보존한 `WIFI-GUARD-Pi5-20261015.zip`은 241,508,466 bytes이고 SHA256은 `a6bd8e863c701137b6538ef57717e3bbf91135b27ae4bf207656a4dc48408409`입니다. 원본 ZIP은 변경하거나 공개 저장소에 업로드하지 않았습니다.

이전 ZIP의 PC 검사는 백엔드 167, Edge 208, Raspberry 110, 웹 87로 고유 테스트 572개였고 실패/skip은 0이었습니다. 24개 release-profile 검사는 Edge 208개의 부분집합입니다. 이전 산출물에서 62개 ARM64 휠의 해시를 확인했지만 PC에서 ARM64 바이너리를 실행한 것은 아닙니다.

이전 합성 RAW 재생은 약 35.156초, 11,256프레임, 모델 64회, 기한 누락 0을 기록했습니다. 별도 약 40.172초 소프트웨어 스택에서는 모델 74회, 모델 P95 188.42ms, 재실 P95 84.018ms, 재실 행 80개를 기록했습니다. 낙상 라우팅용 결과 1건을 주입해 REST/WS·알림 어댑터를 확인했으며 실제 학습 모델의 낙상 판정이 아닙니다. 이 값은 당시 x86 호스트의 측정이지 새 UI/서비스 전체를 실물 Pi5에서 측정한 값이 아닙니다.

이전 스택 검사의 Timescale 경로는 PostgreSQL 호환 어댑터였습니다. **Pi5 native Timescale 확장 실행 확인으로 표기하지 않습니다.** 이번 클라우드 저장소의 별도 Docker native Timescale 검사는 클라우드용 증거이며 Pi5 실물 검증으로 이전하지 않습니다.

## 성능과 정확도 해석

피처 최적화는 중복 계산 제거, 배열 재사용과 커널 캐싱에 중심을 두었습니다. 원본 모델 구조·FP32·3초 창·S3/ACF·A/B 수식은 유지합니다. Q 상위 30개 선택은 모델 학습 때 고정 서브캐리어 정책과 다른 실험 조건입니다. 수치 회귀 통과만으로 이 정책의 낙상 정확도가 같다고 주장하지 않습니다.

화면의 전체 서비스 자원은 Edge/API/UI/DB/nginx/control/monitor의 겹치지 않는 cgroup 측정 합계입니다. 파일 캐시가 포함되며 OS와 외부 브라우저는 서비스 합계 밖입니다. 저장량은 지정 경로가 속한 파일시스템 전체 사용량이지 DB 전용 크기가 아닙니다. 첫 샘플, 필수 서비스 누락, 오래된 스냅샷은 0이 아닌 미측정으로 표시합니다. 단계별 P95는 알림 수신까지의 end-to-end 지연이 아닙니다.

## 이번에 수행하지 않은 검사

실제 Pi5 설치/ESP32 펌웨어/배선·SPI/GPIO, native ARM64 처리·열·장기 저장 안정성, 실제 빈방 기준값의 타당성, 실제 낙상/비낙상 정확도, 외부 운영 SMTP·FCM 도착은 이번 범위 밖입니다. FCM의 테스트용 가짜 전송 성공을 휴대폰 도착 성공이라고 표시하지 않습니다. 이후 [실물 인수 체크](DEPLOYMENT.md#실물-인수-체크)를 별도로 완료해야 합니다.
