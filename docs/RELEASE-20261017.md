미확정 네트워크 변경과 센서 시작을 같은 잠금으로 직렬화하고, 실패 시 이전 연결로 복구합니다.

### 500ms 초과·입력 누락의 원인 관찰과 소프트웨어 개선

- Pi5에서 접근 불가한 비헤더 GPIO controller는 자동 탐색 중 건너뛰고, 명시한 장치의 오류는 숨기지 않습니다.
- READY 레벨 확인 주기를 50ms에서 5ms로 줄이고 전송·handshake·디코드·순번·drop 정보를 제한된 진단 버퍼에 기록합니다.
- 링 버퍼 전체와 선택 배열을 중복 복사하지 않고 필요한 시간 범위를 찾습니다. 서브캐리어 보간은 JIT warmup 후 공유 커널을 사용합니다.
- 불연속 뒤에는 깨끗한 3.02초 입력을 다시 확보하며 잘못된 구간을 억지로 보간하지 않습니다. 대기를 실패 카운터에서 지우지 않고 별도 표시하고 timing gate에 포함합니다.
- 피처·모델뿐 아니라 후처리·durable publish·WAL commit·lock wait·checkpoint 지연을 구분합니다.
- 새 모델 결과는 **WAL + FULL commit이 끝난 뒤에만 접수 완료**입니다. ACK 정리는 별도 연결에서 수행하고 전원 장애 후 중복 재전송은 백엔드 idempotency로 처리합니다.
- 상태 화면용 스냅샷은 별도 writer에서 최신 값으로 합칠 수 있지만, 확정 감지 결과는 같은 방식으로 버리거나 덮어쓰지 않습니다.

이 개선은 0.5초 stride를 모든 상황에서 보장한다는 뜻이 아닙니다. SD 지연·부하·실제 신호 품질을 계속 측정해야 합니다.
원본 FP32 모델, Q 상위 30개 정책, 기존 피처/후처리 수식, 재실 게이트와 정상 퇴실 후 10초 유예는 유지합니다.

### 만료형 수동 푸시

네이티브 실센서 모드에서 수동 TEST만 허용할 수 있게 했습니다. 기본은 모두 OFF입니다.
자동 낙상 푸시를 끈 상태에서도 명시적 허용과 유효 만료 시각이 있을 때 앱의 수동 알림을 처리합니다.
잘못된/과도하게 긴/만료된 허용, 낙상 연계 outbox, 다른 사용자 기기는 차단하며 확인창·분당 제한·권한 범위를 유지합니다.
실제 낙상 결과의 DB 저장은 유지하고 수동 알림 때문에 가짜 낙상 이력을 만들지 않습니다.

서버 native 허용 상한은 12시간, 별도 비공개 인계 도우미의 설정은 8시간입니다.
공개 PR에는 서버 코드·환경 예제·오프라인 preflight만 포함하고, 키/암호화 키 봉투/해제 암호/개인 설치 ZIP은 제외합니다.
Google 인증 성공, FCM 접수, 앱 수신 보고, 사람이 확인한 휴대폰 알림, 실제 낙상 감지는 서로 다른 검증입니다.

## 공개 소스와 조원용 ZIP의 차이

공개 소스에는 모델 로딩/추론/전처리 코드가 있지만 원본 ONNX/PT 가중치는 없습니다.
모델은 [인수 해시](../models/README.md)로 확인한 별도 승인 파일을 사용합니다.
빌드 UI·ARM64 휠·Android APK·DB·RAW·개인 펌웨어도 Git에 넣지 않습니다.
따라서 GitHub 저장소 크기가 개인 완성 ZIP보다 작은 것은 정상입니다.

조원용 ZIP은 기존 장비 업데이트와 APK 설치를 빠르게 하기 위한 별도 비공개 산출물입니다.
키 포함 PRIVATE ZIP은 암호화 여부와 무관하게 공개 PR/Release/Actions artifact에 업로드하지 않습니다.
시연 후 로컬 키 복사본 제거와 Google IAM 키 폐기는 별개이며, 기존 키 폐기는 같은 키를 쓰는 다른 서버에도 영향을 줍니다.

`tools/check-public-source.py`는 index의 파일 경로/크기/키 형식과 서버 인증 JSON을 검사합니다.
모든 종류의 비밀 유출을 완벽히 증명하는 도구는 아니므로 공유 전 검토와 최소 권한 원칙도 유지합니다.
