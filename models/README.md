# 별도 모델 인수 기준

공개 저장소는 모델 구조·전처리·추론 코드를 제공하지만 가중치 바이너리를 배포하지 않습니다. 승인된 파일을 별도 전달받아 `/opt/wifiguard/models/model-fp32.onnx`와 대응 `model-fp32.json`으로 배치합니다. 파일과 metadata를 한 쌍으로 확인합니다.

| 항목 | 승인된 원본 |
|---|---|
| ONNX | FP32, 91,262,033 bytes |
| ONNX SHA256 | `380cfaa26890c94804a663c4f1d84f1f10c84b3d7e2c28a927f7ff1afc162cba` |
| 원본 checkpoint SHA256 | `7cb0b7436f0bc7f93b69e6c39678ebc5a31c707e2777244ec7973a9ecfa68a41` |
| 입력 계약 | `inhouse-fixed-delay-s3-acf-v1` |
| S3 / ACF / 출력 shape | `[1,224,224]` / `[1,1,128,64]` / `[1,64]` |
| 구조·재학습 | 구조 변경 없음, 재학습 없음 |

이 해시는 2026-10-15에 보존한 배포본 metadata에서 확인했습니다. 모델 파일은 Git에 추가하지 않습니다. `verify-release.py`는 완성 ZIP의 파일별 무결성과 FP32 metadata를 확인합니다. 공개 체크아웃에 없는 ZIP manifest를 새로 만들어 모델 출처가 검증됐다고 주장하지 않습니다.

기존 고정 30개 입력에서 ONNX 수치 회귀는 580개 창과 별도 시간순 205개 창, A/B 결정 변경 0으로 기록됐습니다. 학습 데이터 중복 여부는 확인되지 않았으며 이 결과는 수치 회귀이지 정확도 평가가 아닙니다. 현재 Pi5 운영 입력 정책 Q 상위 30개의 정확도 동등성도 별도로 평가해야 합니다. INT8 비교 실험 코드는 포함하지만 승인된 운영 모델은 FP32입니다.
